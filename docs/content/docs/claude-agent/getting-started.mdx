# Getting Started

This guide walks you through starting the NetworkNav app, installing the browser extension, configuring your first Ideal Customer Profile, and scoring your first contacts.

## Prerequisites

Before you begin, ensure you have these installed:

| Requirement | Version | Purpose |
|-------------|---------|---------|
| **Docker** | Latest | Runs the app, PostgreSQL + ruvector, and supporting services via `docker compose` |
| **Chrome/Chromium** | Latest | Host for the browser extension that captures LinkedIn profiles |
| **Claude Code** | Latest | Slash command host for `/linkedin-prospector` and `/network-intel` |
| **Node.js** | 18+ | ES module runtime for the agent scripts (they use only the built-in `fetch` -- no packages to install) |

<Callout type="info">
All intelligence -- scoring, enrichment, graph analysis, semantic search -- runs server-side in the app, backed by PostgreSQL with the ruvector extension. The Claude Agent scripts are a thin REST client; there is nothing to install inside the agent itself.
</Callout>

## Installation

<Steps>

### Start the app

```bash
cd /path/to/network-navigator
docker compose up -d
```

This starts the Next.js app on host port `3750`, PostgreSQL with ruvector, and any supporting services.

### Install the browser extension

1. Open Chrome and navigate to `chrome://extensions`
2. Enable "Developer mode" (toggle in top right)
3. Click "Load unpacked" and select the `browser/dist` directory
4. The NetworkNav icon appears in your toolbar

### Confirm the agent can reach the app

```bash
node agent/network-navigator/skills/linkedin-prospector/scripts/pipeline.mjs --health
```

This checks `/api/health` (app + database) and `/api/extension/health-internal`.

</Steps>

## Configure Your ICP

Tell Claude to walk you through configuration:

```
/linkedin-prospector set up my ICP config
```

Claude will ask about your services, target buyer roles, industries, buying signals, company size, and search niches, then create the ICP profiles, niches, and offerings via the app's REST API. See [ICP Configuration](/docs/claude-agent/icp-configuration) for the full flow.

To verify your config:

```
/linkedin-prospector validate config
```

## Capture Your First Contacts

The agent cannot browse LinkedIn itself -- capture happens through the browser extension as you browse:

1. Navigate to LinkedIn
2. Click the NetworkNav extension icon
3. Open the side panel for bulk capture
4. Browse LinkedIn profiles or search results pages -- the extension captures visible profiles and (if enabled in the popup settings) auto-paginates through search results

Or import an existing LinkedIn data export:

```
POST /api/import/from-directory
{ "path": "/path/to/linkedin/export" }
```

New contacts captured this way are scored automatically.

## Score and Analyze

To trigger a full rescore of everyone (e.g. after changing ICP criteria or scoring weights):

```
/network-intel rescore everything
```

Now explore your network:

```
/network-intel show me my network summary
/network-intel who are my best hubs?
/network-intel find my top prospects
/network-intel who are my best referral partners?
/network-intel what should I focus on next?
```

## Review in the Dashboard

Open `http://localhost:3750` for the full web dashboard -- contacts table, scoring visualization, graph view, and outreach pipeline.

## Complete Zero-to-Scored Walkthrough

For those who prefer running scripts directly:

```bash
# 1. Start the app
docker compose up -d

# 2. Install the browser extension (manual step in Chrome)

# 3. Configure ICP (non-interactive)
node agent/network-navigator/skills/linkedin-prospector/scripts/configure.mjs generate --json '{
  "profiles": {
    "my-service": {
      "name": "My Service",
      "criteria": { "roles": ["CEO","CTO"], "industries": ["saas"], "signals": ["ai"] }
    }
  },
  "niches": {
    "ai": { "name": "AI Leaders", "keywords": ["AI", "machine learning"] }
  },
  "offerings": [{ "name": "My Service" }]
}'

# 4. Validate
node agent/network-navigator/skills/linkedin-prospector/scripts/configure.mjs validate

# 5. Capture contacts via the browser extension (browse LinkedIn)

# 6. Rescore everything
node agent/network-navigator/skills/linkedin-prospector/scripts/pipeline.mjs --rescore-all

# 7. Explore results
node agent/network-navigator/skills/linkedin-prospector/scripts/analyze.mjs --mode summary
node agent/network-navigator/skills/linkedin-prospector/scripts/analyze.mjs --mode hubs --top 10
node agent/network-navigator/skills/linkedin-prospector/scripts/analyze.mjs --mode prospects --top 10
node agent/network-navigator/skills/linkedin-prospector/scripts/analyze.mjs --mode referrals --top 10
```

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `NETWORKNAV_URL` | `http://localhost:3750` | Base URL the agent scripts use for the app's REST API |

## Troubleshooting

| Error | Fix |
|-------|-----|
| App not responding at localhost:3750 | Run `docker compose up -d` and check `docker compose logs app` |
| Extension shows "Not connected" | Confirm the app is up and the extension settings point to `localhost:3750` |
| "No contacts found" | Capture some via the browser extension, or import a LinkedIn export first |
| "Failed to create ICP" | Ensure `criteria` is an object with valid fields (roles, industries, signals) |
| Contacts not scored | Run `/network-intel rescore everything` or `pipeline.mjs --rescore-all` |
| Hybrid/semantic search returns no results | Check that the ruvector-postgres container is running; search falls back to keyword-only otherwise |
