# Commands Reference

The Claude Agent provides two slash commands. Both use natural language intent routing -- you describe what you want and the agent maps your request to the appropriate REST API calls (via `configure.mjs`, `pipeline.mjs`, or `analyze.mjs`, or direct API calls when more convenient).

## /linkedin-prospector

Configuration and management. Handles ICP/niche/offering setup and validation.

### Intent Routing Table

| What to Say | Intent | What Happens |
|-------------|--------|----------------|
| `set up my ICP config` | configure | Conversational ICP/niche/offering setup, then `POST /api/icps`, `/api/niches`, `/api/offerings` |
| `configure my ICP` | configure | Same as above |
| `validate config` | validate | `GET /api/icps`, `/api/niches`, `/api/offerings`; reports counts and warnings |
| `list all profiles` | list | Full listing of configured ICPs, niches, offerings |

### How the Agent Works

1. **Asks about your business** -- Services, target buyer roles, industries, buying signals, company size, and search niches.
2. **Calls the API directly** -- Every configuration change is a REST call; there is no local config file to edit.
3. **Points you at the extension for capture** -- The agent cannot browse LinkedIn itself, so it directs you to the browser extension for profile capture.

### Example Conversation

**Setting up configuration:**
```
User: /linkedin-prospector set up my ICP config
Agent: What services do you offer?
User: vCISO services and managed security assessments
Agent: For "vCISO services", who are your target buyers?
User: CISO, CTO, VP Engineering, IT Director
Agent: What industries are your ideal customers in?
User: fintech, healthtech, SaaS startups
Agent: What keywords signal they need your services?
User: SOC 2, compliance, security audit, cyber insurance
Agent: Created 1 ICP profile, 3 niches, 1 offering. Validation passed.
       Use the browser extension to start capturing LinkedIn profiles.
```

## /network-intel

Scoring, analysis, and reporting. Handles everything that runs against already-captured contacts.

### Intent Routing Table

| What to Say | Intent | What Happens |
|-------------|--------|----------------|
| `rescore everything` | rescore | `POST /api/scoring/rescore-all`, polls `GET /api/scoring/status` until done |
| `show me my network summary` / `give me an overview` | summary | `analyze.mjs --mode summary` (`GET /api/dashboard`) |
| `who are my best hubs?` | hubs | `analyze.mjs --mode hubs` (`GET /api/graph/data`) |
| `find my top prospects` | prospects | `analyze.mjs --mode prospects` |
| `who are my best referral partners?` | referrals | `analyze.mjs --mode referrals` |
| `show network clusters` | clusters | `analyze.mjs --mode clusters` (`GET /api/graph/communities`) |
| `search for "AI startup"` | search | `analyze.mjs --mode search` (`GET /api/contacts/hybrid-search`) |
| `what should I focus on next?` | recommend | `analyze.mjs --mode recommend` (`GET /api/actions/next`) |
| `show contacts at Acme Corp` | company | `analyze.mjs --mode company` |
| `check system health` | health | `pipeline.mjs --health` (`GET /api/health`, `GET /api/extension/health-internal`) |
| `enrich contact [id]` | enrich | `pipeline.mjs --enrich [id]` (`POST /api/enrichment/enrich`) |
| `recompute the graph` | compute-graph | `pipeline.mjs --compute-graph` (`POST /api/graph/compute`) |
| `export my data` | export | `pipeline.mjs --export` (`GET /api/admin/export`, CSV) |

### Example Conversations

**Strategic recommendations:**
```
User: /network-intel what should I focus on next?
Agent: Highest-value next action:
       Enrich contact "Jane Smith" (VP Engineering @ TechCorp) --
       currently unenriched and matched to your AI Consulting ICP.
```

**Referral analysis:**
```
User: /network-intel who can bring me work?
Agent: TOP REFERRAL PARTNERS:
       1. Maria Garcia (referral score: 0.71, gold-referral)
          Persona: white-label-partner
```

**Hybrid/semantic search:**
```
User: /network-intel search for "cloud infrastructure"
Agent: Combined keyword + vector search results:
       1. [gold] Maria Garcia -- Chief AI Officer, driving enterprise cloud adoption
       2. [silver] Chris Lee -- VP Digital Transformation, cloud migration lead
```

<Callout type="info">
The dashboard at `http://localhost:3750` provides the full web UI -- contacts table, scoring visualization, graph view, and outreach pipeline. The agent's `/network-intel` command is a conversational, read-mostly complement to it, not a replacement.
</Callout>
