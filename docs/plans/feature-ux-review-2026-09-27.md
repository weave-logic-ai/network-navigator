# Feature, visualization and implementation repair plan

**Baseline:** `d7f04a2`, `feat/harness-setup`; reviewed 2026-09-27. Planning only: no application fixes in this review. Prior green CI/1,012 tests did not establish the workflow outcomes below.

**Evidence:** **UI** = reproduced in isolated demo `127.0.0.1:3751` (918 contacts); **Code** = traced implementation; **Probe** = synthetic in-memory check, no real attack. Desktop 1280×720; responsive check 390×844. Existing data was read; a temporary secondary selection was cleared back to self. No enrichment, outreach, purge, token creation, uploads or external connector runs were triggered. Extension behavior is code-reviewed, not manually exercised in Chrome.

**Priority:** P1 = correctness/security/workflow blocker; P2 = core usability or robustness; P3 = feature expansion. All tasks below are **Open**. Finish existing behavior before optional scope. This plan refines [R1–R11](../../.planning/research-tools-sprint/08-phased-delivery.md), not a second competing backlog: coordinator should link tasks to those IDs and retain their end-to-end release gates.

## Main conclusions

- Lenses have persistence but no complete save/apply/score contract. “Save current view” saves an old config or `{}`; UI scoring normally bypasses lenses; context-aware scores overwrite global rows.
- Target changes update breadcrumbs without refreshing server-rendered comparisons. Current comparison deltas conflate imported graph coverage with a person's network and use inconsistent score units.
- Group selection dims nodes but leaves the hairball and its edges; overlapping memberships are lost. Conversation and Knowledge tabs fail, for confirmed implementation reasons.
- Several charts/counts and explanatory labels need a common data contract before visual polish. Empty/error/unavailable states and primary actions are inconsistent.
- Local-only exposure reduces risk but does not replace request authorization. Destructive APIs, reflected extension CORS, prefix-token authentication and import/source input boundaries need repair.
